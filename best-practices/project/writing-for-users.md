# Writing for users

Comes from: [[vision]] (users with no technical background).

- Write for a **TV seen from the sofa**: short, plain words, no technical terms.
- Do not name the machinery: no "Proton", "gamescope", "owneetd", "mount", "SSID" in the interface
  ("preparing the game", "Networks nearby").
- Say what happens and what to do next ("The new screen may stay black for up to 30 seconds").
- Errors say what failed in the user's terms (wrong Wi-Fi password), never an error code.
- Third-party names only to say what works with OwneetOS ([[legal-compliance]]).
- The project's own documents follow the same spirit: plain English, short sentences.
