# Design tokens, palettes and layout

Comes from: [[design-direction]], guard [[product-invariants]] (no hard-coded colours).

- **No hard-coded colours**: UI colours come from the palette tokens of `Theme` (eight colour
  tokens per palette).
- **Every palette passes a contrast check:** text ≥ 7:1, secondary text and text on the accent
  ≥ 4.5:1, accent against the background ≥ 3:1.
- Sizes on the **1280×720 design grid** (`Theme.px()`); text sizes follow the "Text size" option
  (`Theme.fs()`; S/M/L/XL = 90/100/120/140 %, text only).
- **5% horizontal TV safe area**; the prompt bar and the safe area never move.
- Fonts: Bricolage Grotesque (titles) and Lexend (UI text), bundled as static instances generated
  by `tools/branding/make-fonts`; never edited by hand. The wordmark SVG is generated by
  `tools/branding/make-wordmark`; never edited by hand.
- "Reduce motion" replaces animations with plain fades.
